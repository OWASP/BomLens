# OWASP BomLens

BomLens is a local-first SBOM generator and open-source risk assessor, and an [OWASP Incubator project](https://owasp.org/www-project-bomlens/). It produces a CycloneDX SBOM, an open-source notice, and a security and license risk report from source code, a container image, a binary, firmware, an SBOM you received, or a HuggingFace AI model. It runs from the CLI or a browser UI on your own machine, with no SaaS.

![BomLens web UI showing the scan overview for a demo project, with items to check first and a severity distribution](https://raw.githubusercontent.com/sktelecom/bomlens/main/docs/images/web-ui-demo.png)

Try the [live demo](https://sktelecom.github.io/bomlens/demo/).

Development happens at [sktelecom/bomlens](https://github.com/sktelecom/bomlens). Please open issues and pull requests there.
